# LMCL 暂停时的状态清单

项目处于半弃坑状态。下表记录留档时的状态，不是排期、认领表或修复承诺。作者说明见 [LMCL 首页](../README.md)。

## 已实现

- 产品身份：LMCL 独立名称、自有图标、关于页与数据目录。保留 HMCL 的归属及许可说明。
- 启动保障：启动前体检、崩溃记录及诊断导出；成功启动后自动快照、快照管理与对比、条件满足时回滚。
- 启动器功能：下载源配置、设置导入导出、Java 发行版偏好、JVM 参数向导、内存优化基础功能。
- 界面：双列组件化主页、账户、存档和游玩记录、M3 Expressive 与经典主题、壁纸玻璃与滚动渐隐。
