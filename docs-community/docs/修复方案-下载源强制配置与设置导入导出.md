### 1.1 下载源实际链路

## 2. 目标与验收

### 2.1 目标

| 编号 | 目标 |
|---|---|
| G1 | 未配置任何自定义下载源时，**没有任何网络下载兜底**；版本列表为空或明确失败 |
| G2 | 未配置时从侧栏下载、新建实例等**需要网络**的入口给出明确提示，并可直接跳到下载源设置；**本地导入游戏文件夹不拦截** |
| G3 | 只有用户填写的主源 + 镜像参与候选链；顺序为 主源 → 镜像 1..5，不再追加 Mojang/BMCLAPI |
| G4 | 导出 `.lmcl.json` 可选择设置类；文件包含版本、时间、产品版本和各设置类原始 JSON |
| G5 | 拖入 `.lmcl.json` 或点导入后，先显示变更预览；用户点“应用”才写盘 |
| G6 | 导入失败/格式不支持时**不修改任何设置**，并给出具体原因 |
| G7 | 上游源码字面不再构造任何内置下载源；`DownloadProviders.java` 登记为第 13 处侵入 |

### 2.2 验收清单

1. 删除/重命名 `community-settings.json` 后启动：
   - 点侧栏“下载” → 弹窗“尚未配置下载源”，带 `[去设置]`；
   - 不产生任何 Mojang / BMCLAPI 请求（可用代理或日志确认）；
   - 下载页版本列表为空或 `FAILED`，不显示官方版本。
2. 只填一个主源 → 版本列表可加载，下载走该主源；**不再回落官方源**。
3. 主源 + 2 个镜像 → 候选顺序与配置一致；镜像地址不可用时只尝试后面的用户镜像，不尝试 Mojang。
4. 删除全部源 → 再点下载 → 重新被拦截。
5. 其他 → 工具 → 导出设置：
   - 勾选“下载源 + 外观 + 主页布局”，导出文件名 `*.lmcl.json`；
   - 文件可被 JSON 解析器解析，含 `format`、`version`、`sections`。
6. 把该文件拖入窗口 → 预览列出变更项 → 点“应用” → 下载源/外观/主页布局生效；点“取消” → 无变化。
7. 拖入损坏 JSON / 未知 `format` / `version > 1` / 只有未知 section → 错误提示，设置不变。
8. 导入包含 `accounts`、密码、Token 的 JSON → 拒绝或忽略，绝不导入账户敏感信息。
9. 未配置下载源时，从“实例 → 导入整合包”选择本地 zip / 游戏文件夹仍可进入安装流程；只有需要远端文件时才失败，并提示配置下载源。
10. 全部通过后，`git diff` 中上游 `.java` 修改为既有 12 处 + 第 13 处 `DownloadProviders.java`，没有其它上游改动。

## 3. 设计 A：下载源零内置

### 3.1 数据语义调整

`CommunityDownloadSources`：

- `empty()` 的语义从“仅官方源”改为“**没有可用下载源**”；
- `isEmpty()` 仍表示 `primary == null && mirrors.isEmpty()`；
- `orderedSources()` 只返回用户配置的源，不追加任何内置源；
- `load()` 失败时仍返回 `empty()`，但 UI 必须提示“读取失败/未配置”，不能静默当成官方源。

`CommunityDownloadSettingsPane` 文案调整：

| i18n key | 旧口径 | 新口径 |
|---|---|---|
| `community.settings.download.hint` | 默认不内置第三方镜像，仅使用官方源 | 默认不内置任何下载源；必须填写主源后才能获取版本列表和下载 |
| `community.settings.download.primary.hint` | 留空表示仅使用官方源；官方源始终作为最后回退 | 留空表示不启用下载；必须填写 BMCLAPI 兼容的 API 根 |

| `community.settings.download.reset.done` | 已恢复默认 | 已清空下载源 |

### 3.2 Provider 链

新增：

`HMCL/src/main/java/org/jackhuang/hmcl/community/download/CommunityDownloadProvider.java`

```java
public final class CommunityDownloadProvider {
    public static DownloadProvider of(CommunityDownloadSources sources) {
        if (sources.isEmpty()) {
            return new MissingDownloadProvider();
        }
        List<DownloadProvider> providers = new ArrayList<>();
        for (CommunityDownloadSource source : sources.orderedSources()) {
            providers.add(new BMCLAPIDownloadProvider(source.url()));
        }
        return new AutoDownloadProvider(providers, List.copyOf(providers));
    }
}
```

`CommunityDownloadInstaller.build(...)` 改为：

```java
static DownloadProvider build(@NotNull CommunityDownloadSources sources) {
    return CommunityDownloadProvider.of(sources);
}
```

删除 `MojangDownloadProvider` import；类注释从“自定义源 + 官方兜底”改为“只用自定义源；空配置时进入 MissingDownloadProvider”。

### 3.3 未配置时的 provider

新增 `MissingDownloadProvider`（同包，package-private 或 public）：

```java
final class MissingDownloadProvider implements DownloadProvider {
    @Override public List<URI> getVersionListURLs() { return List.of(); } // 不会被正常路径使用
    @Override public List<URI> getAssetObjectCandidates(String assetId) { return List.of(); }
    @Override public String injectURL(String baseURL) {
        throw new CommunityDownloadSourceMissingException();
    }
    @Override public List<URI> injectURLWithCandidates(String baseURL) {
        return List.of();
    }
    @Override public VersionList<?> getVersionListById(String id) {
        return new MissingVersionList(id);
    }
    @Override public int getConcurrency() { return 1; }
}
```

`MissingVersionList`：

```java
final class MissingVersionList extends VersionList<RemoteVersion> {
    @Override public boolean hasType() { return false; }
    @Override public Task<?> refreshAsync() {
        return Task.supplyAsync(() -> {
            throw new CommunityDownloadSourceMissingException();
        });
    }
}
```

要点：

- `getVersionListById(...)` 返回一个 **refresh 会失败的 VersionList**，既不联网，也不会在 `GetTask` 构造处抛 `IndexOutOfBoundsException`；
- `getVersionListURLs()` 返回空列表只作为最后防线；正常 UI 走 `getVersionListById`，不会触发它；
- `injectURL` 抛 `CommunityDownloadSourceMissingException`，让依赖该 URL 的下载任务明确失败，绝不回到官方 URL；
- `CommunityDownloadSourceMissingException extends RuntimeException`，带 i18n key `community.download.error.not_configured` 供日志/未来 UI 使用，不直接显示给用户。

### 3.4 UI 守卫

新增：

接入点：

## 4. 设计 B：`.lmcl.json` 格式

### 4.1 文件后缀与命名

- 后缀：`.lmcl.json`（大小写不敏感）；
- 默认文件名：`LMCL-settings-<yyyyMMdd-HHmmss>.lmcl.json`；
- 文件编码 UTF-8，2 空格缩进；
- 单文件上限：2 MiB（导入时检查）。

### 4.2 顶层结构

```json
{
  "format": "lmcl.settings",
  "version": 1,
  "product": "Lumina Minecraft Launcher",
  "productVersion": "3.16.1000",
  "exportedAt": "2026-10-22T12:34:56Z",
  "sections": {
    "downloadSources": { },
    "appearance": { },
    "home": { },
    "memory": { },
    "java": { }
  }
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `format` | 是 | 固定 `"lmcl.settings"`，用于拖入识别 |
| `version` | 是 | 当前 `1`；`> 1` 时只读提示，不导入 |
| `product` | 否 | 导出时的产品名，仅展示 |
| `productVersion` | 否 | 导出时的版本，仅展示/兼容 |
| `exportedAt` | 否 | ISO-8601，用于预览 |
| `sections` | 是 | 至少包含一个受支持的 section |

### 4.3 设置类（sections）

第一批支持 5 类：

| id | 名称 | 数据来源 | 说明 |
|---|---|---|---|
| `downloadSources` | 下载源 | `community-settings.json` 的 `downloadSources` 段 | 主源 + 镜像 |
| `appearance` | 外观 | `LauncherSettings` 的显示字段 | 主题、颜色、背景、字体、动画、语言 |
| `home` | 主页布局 | `dashboard.json` | schema、columns、items、pinnedInstanceIds、widgetProps |
| `memory` | 内存优化 | `community-settings.json` 的 `memoryBase` 段 + 全局默认 `memoryOptimizationOnLaunch` | 不含单个实例的 JVM 参数 |
| `java` | Java 偏好 | `community-settings.json` 的 `java` 段 | 偏好发行版、镜像开关 |

**不导出**：

- 账户、Token、authlib-injector 服务器；
- 代理用户名/密码；
- 绝对路径类的游戏目录、Java 路径、日志路径；
- 单实例的 JVM 参数/内存值（避免把 A 机器的路径带到 B 机器）；
- 崩溃记录、游玩记录、快照（属于运行数据，不是“启动器设置”）。

### 4.4 appearance 白名单

只允许以下键（与 `LauncherSettings` 的 `@SerializedName` 一致）：

```
language
selectedTheme
themeAppearanceOverrides
themeBrightnessMode
customThemeColor
themeColorType
themeColorStyle
titleBarTransparent
windowTransparent
backgroundType
builtinBackgroundId
backgroundOpacity
networkBackgroundImageCachePolicy
backgroundFallbackType
backgroundLoadPolicy
logFontFamily
logFontSize
launcherFontFamily
animationDisabled
```

- 不导出 `customBackgroundImagePath` / `networkBackgroundImageUrl`（本机路径/外部 URL，跨机器无意义且可能泄露路径）；
- 不导出 `acceptPreviewUpdate`、`disableAutoShowUpdateDialog`、`disableAprilFools`（更新策略独立，避免导入后改变更新行为）；
- 不导出 `versionListSource` / `fileDownloadSource`（已被社区下载源取代，导入会误导）。

### 4.5 各 section 结构

#### downloadSources

直接复用现有 schema：

```json
{
  "schema": 1,
  "primary": { "name": "示例", "url": "https://example.com" },
  "mirrors": [
    { "name": "镜像 1", "url": "https://mirror1.example.com" }
  ]
}
```

导入校验：URL 必须 http/https、去尾斜杠、去重、镜像 ≤ 5；非法条目丢弃并在预览中标注。

#### appearance

```json
{
  "language": "zh_CN",
  "selectedTheme": { "packId": "hmcl.default", "colorScheme": "..." },
  "themeBrightnessMode": "auto",
  "customThemeColor": "#6750A4",
  "themeColorType": "DEFAULT",
  "themeColorStyle": "FIDELITY",
  "titleBarTransparent": false,
  "windowTransparent": false,
  "backgroundType": "DEFAULT",
  "builtinBackgroundId": "...",
  "backgroundOpacity": 1.0,
  "animationDisabled": false,
  "launcherFontFamily": "",
  "logFontFamily": "",
  "logFontSize": 12,
  "themeAppearanceOverrides": []
}
```

具体 JSON 形状以 `JsonUtils.GSON.toJsonTree(settings())` 中对应键为准，不手写枚举名。

#### home

```json
{
  "schema": 1,
  "columns": "auto",
  "items": [
    { "id": "launch", "enabled": true, "order": 10, "colSpan": 2, "rowSpan": 1 }
  ],
  "pinnedInstanceIds": [],
  "widgetProps": {}
}
```

导入校验：

- `schema > 1` → 只读提示，不导入；
- `items` 最多 30 项；
- 未知 `id` 保留但不注册（`WidgetRegistry` 会跳过）；
- `colSpan`/`rowSpan` 只允许 1/2；
- `pinnedInstanceIds` 去重，最多 12 个（与置顶卡上限一致）；
- `widgetProps` 必须是对象。

#### memory

```json
{
  "memoryBase": {
    "enabled": true,
    "intervalMinutes": 10,
    "minReclaimMiB": 128
  },
  "memoryOptimizationOnLaunch": true
}
```

- `memoryBase` 复用 `MemoryBaseSettings` 的字段；
- `memoryOptimizationOnLaunch` 写全局默认 `GameSettings.Preset` 的 `memoryOptimizationOnLaunchProperty()`；不导出单实例值；
- 不导出 `lastReclaimAt` / `totalReclaimedMiB` / `disabledReason`（运行状态）。

#### java

```json
{
  "preferredDistribution": "ZULU",
  "mirrorEnabled": true
}
```

- `preferredDistribution` 必须是 `DiscoJavaDistribution` 的枚举名或 `ANY`；
- `mirrorEnabled` 只在镜像已部署时有意义；未部署时保留值但不启用。

### 4.6 版本与兼容

- `version = 1` 为当前唯一可写版本；
- 导入 `version > 1`：错误 `community.settings.transfer.error.version`，不写入；
- 未知 section：跳过并在预览中列“已忽略”；
- 未知字段：在该 section 内保留（写回时合并），但预览不展示。

### 5.3 导出器契约

```java
public interface SettingsSectionExporter {
    String id();                       // downloadSources / appearance / ...
    String titleKey();
    JsonObject exportNow();            // FX 线程读内存设置，返回可序列化 JSON
    List<SettingsChange> preview(JsonObject incoming); // 不修改
    void apply(JsonObject incoming);   // 仅预览确认后调用
}
```

实现：

- `DownloadSourcesSectionExporter`：`CommunitySettings.get().section("downloadSources")`；apply 用 `CommunityDownloadSources.parse(...).save()`；
- `AppearanceSectionExporter`：`JsonUtils.GSON.toJsonTree(SettingsManager.settings()).getAsJsonObject()` 过滤白名单；apply 逐键解析并写回属性；
- `HomeSectionExporter`：`DashboardConfig.load(path).toExportJson()`；apply 先 `validate`，再 `replaceFromJson` + `save()`；
- `MemorySectionExporter`：读 `memoryBase` + 默认 preset 的 `memoryOptimizationOnLaunch`；
- `JavaSectionExporter`：`JavaPreference.get()` 转 JSON；apply 走 `JavaPreference.set(Preference)`（本步新增该方法，允许同时写 distribution 与 mirrorEnabled）。

`SettingsChange`：

```java
public record SettingsChange(
        String section,
        String key,
        @Nullable String oldValue,
        @Nullable String newValue) {}
```

预览只比较“将变化”的项；未变化项不展示。复杂值用简短文本（`shortJson`，最多 80 字符）。

## 6. 设计 D：导入预览与应用

### 6.1 读取与校验

新增 `CommunitySettingsBundle`：

```java
public record CommunitySettingsBundle(
        int version,
        String product,
        @Nullable String productVersion,
        @Nullable Instant exportedAt,
        Map<String, JsonObject> sections) {

    public static CommunitySettingsBundle parse(JsonObject root);
    public JsonObject toJson();
}
```

校验顺序：

1. 文件存在、可读、≤ 2 MiB；
2. 顶层是 JSON object；
3. `format == "lmcl.settings"`；
4. `version == 1`（`> 1` 明确提示升级启动器）；
5. `sections` 是 object 且至少含一个受支持 section；
6. 每个 section 必须是 object；
7. 逐 section 校验（见 4.5）。

任何一步失败 → `CommunitySettingsImportException`（带 i18n key），**不写盘**。

### 6.2 预览对话框

`SettingsImportDialog`（`community/ui/transfer`）：

```text
DialogPane 640 宽
├─ 标题：导入启动器配置
├─ 文件：<name> · 导出于 <time> · 来自 v<productVersion>
├─ 摘要：将修改 3 类设置，共 12 项；忽略 1 个未知 section
├─ ScrollPane
│   ├─ 下载源（2 项）
│   │   ├─ 主源：<空> → https://example.com
│   │   └─ 镜像：<空> → https://mirror.example.com
│   ├─ 外观（8 项）
│   │   ├─ 主题亮度：auto → dark
│   │   └─ ...
│   └─ 主页布局（1 项）：10 个组件 → 12 个组件
├─ 警告：导入会覆盖同类设置，建议先在“导出设置”里备份
└─ [取消] [应用]
```

- 最多列出 50 项，多余显示“还有 N 项”；
- 复杂值用 `shorten`；
- `[应用]` 前禁用按钮，防重复点击；
- 预览不修改任何设置，关闭即丢弃。

### 6.3 应用顺序

1. `downloadSources`：校验 → `save()` → `CommunityDownloadInstaller.apply()`；
2. `appearance`：逐属性写回；主题/背景监听器会刷新；
3. `home`：`DashboardConfig.replaceFromJson` → `save()` → `HomePane.reloadFromDisk()`（若已挂载）；
4. `memory`：`MemoryBaseSettings` 保存 + 默认 preset 属性；
5. `java`：`JavaPreference.set(...)`。

失败处理：

- 每个 section 独立 try/catch；
- 成功/失败汇总到 `ImportResult(List<String> applied, List<SectionFailure> failed)`；
- 部分失败时提示“以下设置未能应用：…”，已成功的不回滚；
- 全部失败时保持原设置不变。

### 6.4 拖入识别

新增 `CommunityConfigDnD`：

```java
public final class CommunityConfigDnD {
    public static EventHandler<DragEvent> dragOverHandler();
    public static EventHandler<DragEvent> dragDroppedHandler(Consumer<Path> onFile);
}
```

规则：

- `event.getDragboard().hasFiles()`；
- 第一个文件的文件名（小写）以 `.lmcl.json` 结尾；
- `acceptTransferModes(TransferMode.COPY)`；
- 放下后 `setDropCompleted(true)`、`consume()`，把文件交给导入预览；
- 其它文件/URL 不拦截，交给原有处理器。

接入：`DecoratorController` 构造中已有 `setupAuthlibInjectorDnD()`（`DecoratorController.java:71`、`:258-261`），在其中追加：

```java
decorator.addEventFilter(DragEvent.DRAG_OVER, CommunityConfigDnD.dragOverHandler());
decorator.addEventFilter(DragEvent.DRAG_DROPPED, CommunityConfigDnD.dragDroppedHandler(this::openImportPreview));
```

- 与 authlib-injector 的 DnD 不冲突：那边只识别 `authlib-injector:yggdrasil-server:` 字符串，本方案只识别文件；
- `DecoratorController` 已在第 12 处侵入清单内，不新增侵入；
- `openImportPreview(Path)` 在 FX 线程读取文件；读取/解析放 `Schedulers.io()`，回 FX 显示对话框。

### 6.5 文件内容安全

- 不执行任何文件路径、命令、URL；
- `appearance` 的路径字段已排除；
- 导入 `home` 只写 `dashboard.json`，不写其它文件；
- 拒绝包含 `accounts`、`authlib-injector-servers`、`proxy` 等未列入白名单的 section；
- 如果 JSON 中含 `password`/`token` 字段，直接忽略并记录（不显示值）。

## 10. 风险与对策

| 风险 | 级别 | 对策 |
|---|---|---|
| 未配置时版本列表失败但 UI 无原因 | 高 | `CommunityDownloadGuard` 拦截主要入口；`MissingVersionList` 让状态为 FAILED |
| 用户已有官方源配置，升级后突然不能下载 | 高 | 升级提示：首次启动/打开下载页提示“需要手动配置下载源”；不清除旧配置 |
| 上游某个内部调用直接走 `getVersionListURLs()` | 中 | `MissingDownloadProvider` 返回空列表会抛异常；通过日志监控并补守卫 |
| 导入覆盖用户设置且无法撤销 | 高 | 预览 + 二次确认；建议先导出备份；保存 `dashboard.json` 等原文件 `.bak` |
| appearance 字段跨版本不兼容 | 中 | 白名单 + 逐键解析；未知键忽略并提示 |
| 拖入事件与 authlib 冲突 | 低 | 只处理文件，不处理字符串；两个 filter 互不 consume |
| 导出文件包含本机路径 | 中 | 白名单排除路径/URL 字段；单测断言 |
| `MissingDownloadProvider` 直接抛异常导致 FX 崩溃 | 中 | 异常只在下载任务内抛出；UI 守卫在任务创建前拦截；所有入口 try/catch |
