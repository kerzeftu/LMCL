## 1. 目标与范围

### 1.1 要解决的问题

1. 删除主页问候语下方的固定文案 `community.home.subtitle`（“从上次停下的地方继续” / “Pick up where you left off”），不再保留这个“上次停下的地方”的暗示。
2. 在同一个位置（`HomePane` 顶部问候语下方、运行状态左侧）放一条**每日一言**，作为主页的低干扰信息行。
3. 本地内置语料覆盖两类内容：
   - **MC 风味语句**：LMCL 自写，围绕生存、建造、红石、服务器、Mod、存档等场景；
   - **经典诗词**：公版中文古诗词，带作者与篇名。
4. 可选联网获取：在用户允许时从公开诗词/文学源获取内容，默认**每 10 分钟刷新一次**；断网、超时或接口异常时静默保留上一条可用内容，从未成功过则显示内置语句。
5. 设置入口放在 **设置 → 外观**，提供显示开关、联网开关、今日预览与手动重新获取；不新开设置页。

### 1.2 不在本方案内

- 不做用户自定义语句编辑、导入导出、收藏、历史记录、点赞/举报。
- 不做账号云同步，不把每日一言上传到任何 LMCL 服务。
- 不改主页卡片布局、`dashboard.json`、左右栏排序、账户卡、日历卡和其它 9 张组件卡。
- 不重做 M3 切片 B–G；每日一言沿用现有 M3/主题 token，不新增 M3 组件库。
- 不新增上游代码侵入点。设置段落挂在已有的第 12 处 `PersonalizationPage.java` 上。

### 1.3 成功标准

- 3 份 `I18N*.properties` 不再出现 `community.home.subtitle`；主页顶部不再显示该句。
- 每日一言在主页顶部稳定显示一行；超长文案以省略号收尾，完整内容可通过 tooltip 查看；不换行、不挤压运行状态。
- 断网、关闭联网、接口超时、接口返回空内容时，主页都能显示上一条可用内容或内置语句，不弹错误框、不出现空白行。
- 联网默认每 10 分钟刷新一次，只在主页可见且窗口聚焦时计时；切到后台暂停，恢复时如已过期立即刷新。失败自动退避，不向用户报错。
- 设置 → 外观出现“每日一言”区；切换显示/联网后回到主页立即生效，不需要重启。
- `:HMCL:compileJava`、`:HMCL:checkTranslations`、community 测试、全量测试、`:HMCL:makeExecutables` 全部通过；文档与测试包同步。

## 3. 设计决策

| 编号 | 决策 | 理由 |
|---|---|---|
| D1 | 删除 `community.home.subtitle`，同一 `statusRow` 改为“每日一言 + 运行状态” | 用户明确要求；不新增卡片、不改变顶部高度结构 |
| D2 | 内置语料 **120 条**：60 条 MC 风味 + 60 条公版诗词 | 离线可用、内容质量可控；按自然日交替两类，避免长期只出现一种 |
| D3 | 联网源先按 **Hitokoto** 设计，保留 `QuoteProvider` 抽象；今日诗词/自有静态源可选 | 无 token、接入最快；公开大规模发布前切自有静态源，避免长期压公益接口 |
| D4 | 联网默认 **开启**，主页可见且聚焦时每 **10 分钟**刷新；后台暂停，恢复时过期立即刷新 | 用户明确要求 10 分钟；暂停后台请求降低隐私与流量影响 |
| D5 | 缓存保留最近一次在线结果，TTL 10 分钟；失败不清空、不弹框，保留上一条或回退内置 | 静默降级；重启不重复请求 |
| D6 | 内置语句按 `LocalDate` 的 epochDay 计算，不用 `Random` | 同一天多次启动结果一致；不需要持久化“今天抽到第几条” |
| D6b | 自动请求带 0–60 s 抖动；连续失败按 10 → 20 → 40 → 60 分钟退避 | 避免大量客户端在同一秒请求，也避免断网时每 10 分钟撞一次 |
| D7 | 设置放在 `PersonalizationPage` 末尾，复用第 12 处侵入 | 不新增上游文件，也不另建设置页 |
| D8 | 顶栏只显示一行；最多约 72 个显示字符，超出省略，tooltip 展示全文与出处 | 不挤压问候语、运行状态和“自定义”按钮；长句不换行 |
| D9 | 手动“重新获取”只放在设置预览区，主页不放置刷新按钮 | 主页保持低干扰；需要换一句时到设置里操作 |
| D10 | 不做设置导入/导出接入（P1 可选） | 控制本次范围；两个布尔开关不属于用户核心迁移数据 |

## 4. 内置语料

### 4.1 资源文件

新增：

```text
HMCL/src/main/resources/assets/community/daily-quotes.json
```

结构：

```json
{
  "schema": 1,
  "quotes": [
    {
      "text": "背包再满，也记得给自己留一格。",
      "author": "",
      "source": "LMCL 编辑",
      "kind": "minecraft"
    },
    {
      "text": "星垂平野阔，月涌大江流。",
      "author": "杜甫",
      "source": "旅夜书怀",
      "kind": "poetry"
    }
  ]
}
```

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `text` | 是 | 语句正文，1–120 字符；不得为空或纯空白 |
| `author` | 否 | 诗词作者；MC 风味语句留空 |
| `source` | 否 | 诗词篇名（不带书名号）；MC 风味语句固定 `LMCL 编辑` |
| `kind` | 是 | `minecraft` 或 `poetry`；决定日期交替分组 |

加载失败、schema 不符或条目不足时：

- 记录 `LOG.warning`；
- 使用代码内的 6 条最小后备语句（3 条 MC + 3 条诗词），保证主页永不空白；
- 不因资源损坏阻止启动。

### 4.2 内容规则

**MC 风味语句**（60 条，原创）：

- 主题覆盖：生存第一天、挖矿、建造、红石、农场、服务器、Mod、整合包、存档、备份、Java、启动等待、朋友联机。
- 不复制 Minecraft 官方文本、成就描述、社区梗原句；不使用商标做产品宣传。
- 语气克制、有画面感，不写“肝”“氪”等重度网络词，不写攻击性内容。
- 示例：
  - “挖三填一，也是向世界问好。”
  - “出生点的第一棵树，值得记住它的坐标。”
  - “红石灯亮起之前，先给自己一点耐心。”
  - “存档备份不是胆小，是给明天留一扇门。”

**经典诗词**（60 条，公版）：

- 只选唐宋及以前、作者已进入公有领域的作品；不选现代诗、歌词、网络金句。
- 每条的 `author` 与 `source` 必须可核对；篇名用常见名，不加书名号。
- 优先选择与“等待、出发、建造、朋友、夜晚、远方”相关的意象，避免过度悲苦或生僻典故。
- 示例：
  - 星垂平野阔，月涌大江流。 —— 杜甫《旅夜书怀》
  - 海内存知己，天涯若比邻。 —— 王勃《送杜少府之任蜀州》
  - 长风破浪会有时，直挂云帆济沧海。 —— 李白《行路难》
  - 山重水复疑无路，柳暗花明又一村。 —— 陆游《游山西村》

### 4.3 日期选择算法

```text
day = LocalDate.now().toEpochDay()
kind = day 为偶数 ? poetry : minecraft
seq = floorDiv(day, 2)
index = floorMod(seq, 该 kind 的条目数)
```

效果：

- 同一天所有启动结果一致，不依赖随机种子；
- 奇偶日交替 MC/诗词；
- 语料增减不会影响另一类的索引；
- 不使用 `Math.abs(Integer.MIN_VALUE)`，用 `floorMod` 避免负数取模问题。

### 4.4 展示格式

| 来源 | 文本 | 出处 |
|---|---|---|
| 内置 MC | 正文 | `— LMCL 编辑` |
| 内置诗词 | 正文 | `— 杜甫《旅夜书怀》` |
| 联网有作者/出处 | `text` 去换行 | `— 作者《出处》`，末尾追加 `· 来源名` |
| 联网只有出处 | `text` | `— 出处 · 来源名` |
| 联网无出处 | `text` | `— 来源名` |

正文与出处分行只在设置预览区使用；主页顶栏采用单行“正文 — 出处”，超出省略。

## 5. 联网获取

### 5.1 可选联网源

| 源 | 接入方式 | 内容 | 优点 | 限制 |
|---|---|---|---|---|
| **Hitokoto 一言** | `GET https://v1.hitokoto.cn/?c=i&min_length=8&max_length=60&encode=json&charset=utf-8` | 诗词类（`c=i`）；可选文学（`c=d`） | 无需 token、JSON、接入最快；HTTPS、有公开文档 | 公益服务；文档标称 2 QPS；内容为用户投稿，质量参差；无稳定性承诺；10 分钟/客户端的请求量对公开大规模分发偏高 |
| **今日诗词 Jinrishici** | 先 `GET https://v2.jinrishici.com/token`，再 `GET https://v2.jinrishici.com/sentence`，带 `X-User-Token` | 古诗词，含朝代、作者、篇名 | 内容质量稳定；官方按 10 分钟更新推荐缓存，和本方案节奏一致；桌面端明确支持高级 JSON 接口 | 需要按安装保存 token；免费仅限非商用、不支持服务端调用；会获取 IP/token 用于推荐；文档限制 5 秒 25 次/IP |
| **LMCL 自有静态 JSON** | 部署 `https://www.kerzeftu.top/lmcl/api/daily-quotes.json`，一次拉取一组，客户端每 10 分钟轮换 | MC 风味 + 诗词都可控 | 内容和版权完全可控；不依赖第三方接口；一次拉取后本地轮换，不给外部造成每 10 分钟一次的压力 | 需要先部署和维护；首次仍要靠内置语料兜底 |
| **gushi.ci 旧接口 / GitHub raw** | 旧版诗词接口 / `raw.githubusercontent.com`、jsDelivr 静态文件 | 古诗词/静态 JSON | 接入简单、无需 token | 旧接口文档和维护弱；raw/jsDelivr 在部分网络环境不稳定；不建议作为唯一源 |
| **ONE / 第三方聚合 API** | 各类非官方 `api.*/one` | 混合句子 | 内容多 | 非官方、无 SLA、版权和内容边界不清、随时失效；不采用 |

**推荐路径**：

- **本轮实现默认 Hitokoto**（只取 `c=i`，不取 `c=d`，避免混入现代文学片段）：无 token、最快验证顶栏和 10 分钟刷新交互。
- **若你接受 token、且更看重诗词质量**：改默认 **今日诗词**，它返回朝代/作者/篇名，且官方缓存周期正好是 10 分钟。
- **公开发布前建议切 LMCL 自有静态 JSON**：客户端每 10 分钟本地轮换，网络只在启动/手动刷新时拉一次词库，不把公益接口当 CDN 用。
- 不推荐把 ONE 等非官方聚合接口作为默认源。

### 5.2 请求时机与频率

只有同时满足以下条件才自动请求：

1. 每日一言显示开关为开；
2. 联网开关为开；
3. 主页当前可见且窗口聚焦（最小化/切到后台暂停计时）；
4. 距离上次成功获取已超过 10 分钟（缓存 TTL）；
5. 当前没有进行中的请求（in-flight 去重）。

行为：

- 启动/回到主页时先立即显示最近缓存（即使已过期）或内置语句，再异步请求，不出现空白或加载骨架。
- 前台每 10 分钟触发一次；首次触发带 0–60 s 随机抖动，避免大量客户端同一秒请求。
- 切到后台时停止 `Timeline`；回到前台时若 `now - lastAttempt >= 10 min`，立即补一次。
- 连续失败按 10 → 20 → 40 → 60 分钟退避；成功后重置为 10 分钟。
- 手动“重新获取”绕过 TTL，但两次点击至少间隔 3 s，请求期间按钮禁用。
- 超时：连接 3 s，请求 5 s；自动请求只尝试一次，不自动重试。
- 响应正文上限 64 KiB；超过视为失败。

### 5.3 失败与静默降级

显示顺序：

1. 最近一次成功缓存（无论是否超过 10 分钟，先显示）；
2. 内置语句（从未成功或缓存损坏时）。

刷新结果：

- **自动请求失败**：不弹框、不显示红点、不写错误提示；保留当前显示内容，日志用 `LOG.debug`。
- **首次自动请求失败**：显示当天内置语句，主页不出现空白。
- **设置页手动请求失败**：保留当前内容，只在预览区显示一行浅色“获取失败，保留当前内容”，不弹 `MessageDialog`。
- **接口返回空正文、HTML、非 JSON、HTTP 非 2xx、超过 64 KiB**：一律视为失败。
- **缓存文件损坏**：忽略并记录 `LOG.warning`，不删除用户其它数据；下次成功请求覆盖。
- 联网关闭后不发起任何 DNS/HTTP 请求；已有缓存保留但不显示联网来源标记。

### 5.4 隐私与内容边界

- 联网只发送 IP、User-Agent、固定查询参数；使用今日诗词时额外发送安装级 token。不发送账户、实例、存档、UUID 或本地路径。
- 关闭联网后，该功能不发起任何请求；本地语料仍可显示。
- 不缓存第三方接口的完整响应，只缓存展示所需的正文、作者、出处、来源标记和 `fetchedAt`。
- Hitokoto 内容为第三方用户投稿；界面标注“一言”，不把其内容包装成 LMCL 原创。今日诗词内容同理标注“今日诗词”。
- 不在代码或资源中内置第三方歌词、网络热门段子、Minecraft 官方宣传文案。
- 公开分发前复核所选源的商用/再分发条款；当前 LMCL 免费，符合 Hitokoto/今日诗词的非商用条件。

### 5.5 Provider 抽象

```java
public interface QuoteProvider {
    DailyQuote fetch() throws Exception;
}
```

- 本轮默认实现 `HitokotoQuoteProvider`；若选今日诗词，则新增 `JinrishiciQuoteProvider` + `JinrishiciTokenStore`，`DailyQuoteService` 不变。
- 自有静态源实现 `StaticQuoteProvider`：一次拉取 JSON 数组，缓存在内存/磁盘，每 10 分钟按索引轮换；网络只在词库缺失或过期（例如 24 小时）时发生。
- 任何 provider 只负责“取一条”，不负责 UI 定时器、缓存和开关；这些由 `DailyQuoteService` 统一处理。
- 首版不内置联网源切换 UI；默认由代码常量选择，避免设置项膨胀。若后续允许用户换源，再加设置段。

## 6. 数据与缓存

### 6.1 设置段

`CommunitySettings` 顶层新增 `dailyQuote`：

```json
{
  "dailyQuote": {
    "enabled": true,
    "online": true
  }
}
```

读取规则：

- 缺字段：`enabled`、`online` 均默认 `true`；
- 类型错误或读取异常：按默认值处理并 `LOG.warning`，不阻断主页；
- 不把“今日内容”写进设置文件，避免设置文件随时间膨胀。

### 6.2 缓存文件

路径：

```text
<本地根>/community/daily-quote.json
```

结构：

```json
{
  "schema": 1,
  "text": "星垂平野阔，月涌大江流。",
  "author": "杜甫",
  "source": "旅夜书怀",
  "origin": "online",
  "fetchedAt": "2026-10-24T01:40:00+08:00"
}
```

规则：

- 缓存保存“最近一次成功获取”，不按自然日失效；`fetchedAt` 是唯一新鲜度依据；
- `now - fetchedAt < 10 分钟` 视为新鲜，否则视为过期并触发刷新；
- 过期缓存**不删除**，主页仍先显示它，直到新请求成功或用户关闭联网；
- `fetchedAt` 在未来超过 2 分钟视为时钟异常，按过期处理；
- `origin` 只允许 `online`；内置语句不需要缓存；
- 联网关闭时不读取缓存、不显示联网内容，但保留文件供下次开启；
- 写入使用临时文件 + `ATOMIC_MOVE`，失败只记日志；
- 文件损坏时不崩溃；可保留原文件供排查，不在这里做 `.corrupt` 重命名，避免额外 IO 分支；
- 缓存目录不存在时自动创建。

### 6.3 线程

- 资源加载：类初始化时一次性读取，之后只在内存取；不反复读盘。
- 设置段读写：与现有 `CommunitySettings` 一致，操作很小；设置页点击时可以同步写，若后续实测卡顿再迁到 `Schedulers.io()`。
- 缓存读写、联网：全部在 `Schedulers.io()`；回到 FX 用 `Schedulers.javafx()`。
- 主页刷新使用单调递增的请求序号 + `fetchedAt` 校验，避免旧请求覆盖新结果或新设置。
- `HomePane.dispose()` 取消 `Timeline`、清空弱引用、停止后续 UI 更新。

## 11. 风险与回退

| 风险 | 影响 | 缓解 |
|---|---|---|
| 所选源不可用/返回低质内容 | 联网体验不稳定 | 保留旧内容、首次回退内置；只取诗词类；限制 64 KiB；不向 UI 抛错 |
| 10 分钟刷新给公益接口造成压力 | 被限流或封禁 | 仅在主页可见/聚焦时请求；0–60 s 抖动；失败退避；公开分发前切自有静态源 |
| 第三方内容版权/合规 | 分发争议 | 不内置第三方内容；界面标注来源；可切换到自有静态源 |
| 长句挤压顶栏 | 运行状态/按钮不可见 | 单行省略 + minWidth 0 + tooltip；窄窗隐藏出处优先保留正文 |
| 隐私顾虑 | 用户不希望联网 | 默认每 10 分钟但仅前台；设置可完全关闭；关闭后无请求 |
| 时钟异常 | 缓存永不刷新或频繁刷新 | TTL 用 `fetchedAt`；未来时间戳按过期；失败退避上限 60 分钟 |
| 设置写入失败 | 开关视觉与实际不符 | 写失败只日志，UI 回读实际值；提供默认值 |
| 新增 i18n 重复/占位符错误 | `checkTranslations` 失败 | 实现前先查重复；全部 key 三份同步 |

回退：

- 删除 `DailyQuoteSettingsPane` 注入，主页恢复为仅运行状态；
