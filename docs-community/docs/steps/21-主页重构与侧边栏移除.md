## 1. 目标

解决"主页已经能完成大部分操作，但左侧 200 px 文本侧栏仍然重复一遍"的结构问题：

- **移除** `RootPage.Skin` 中的 200 px 文本侧栏（账户、实例、版本管理、下载、设置、Terracotta、反馈）；
- 把上述入口**收进主页**：顶部导航 + 当前账号 chip + 右栏账户卡；不新增页面、不改 `Controllers`；
- 主页参考美西螈启动器（Axolotl）的"顶栏 + 主列 + 右信息栏"结构：
  - 主列：启动卡、置顶实例、最近世界、存储、Java 推荐；
  - 右栏：当前账号、活动日历、内存、崩溃历史、体检、下载源、快照；
- 不再用 2×2 固定网格摆放全部卡片；首页首屏是**可滚动的主列/右栏**，窄窗口仍可滚动阅读。

完成标志（DoD）：

- [x] 启动器根页面不再渲染 200 px 文本侧栏；主内容区占满窗口宽度（空 `left` 不再被 Skin 限宽）；
- [x] 账户、实例管理、下载、启动器设置、Terracotta、反馈均可在主页找到入口；
- [x] 当前账号在顶部 chip 与右栏账户卡两处显示，点击进入账户页；
- [x] 11 张既有卡片全部保留；默认全部启用，按主列/右栏固定槽位摆放；
- [x] 组件显隐仍可配置（编辑对话框），配置继续写 `dashboard.json`；不破坏旧布局文件；
- [x] 运行状态只信步骤 08 的 `CommunityLaunchHooks` 事件，不调 `countMangedProcesses` 猜测；
- [x] 所有新增文案三份语言齐全，`CheckTranslations` 通过；
- [x] `:HMCL:compileJava`、community 测试（132/0）、`shadowJar`、`makeExecutables` 通过；
- [ ] GUI 实机验证（Windows 包双击；WSL2 无 DISPLAY，由用户验收）。

## 2. 背景与决策

### 2.1 用户反馈

用户原话（m07850）：

> "这个 ok 了，主页的面板和左侧侧边栏实际功能重合，拟移除左侧侧边栏，参考美西螈启动器的主页面板结构设计制作主页。"

此前 fix2 已让首页仪表盘、下载设置页接管生效；但 `RootPage.Skin` 仍渲染 200 px 文本侧栏，和主页卡片功能重复。

### 2.2 参考结构（Axolotl）

本地截图：`.reference/axolotl/launcher-home.webp`（来源 `https://axlmc.org/showcase/launcher-home.webp`）。

| 区域 | 参考做法 | LMCL 映射 |
|---|---|---|
| 顶栏 | 面包屑/运行状态/操作按钮 | 问候 + 副标题 + 运行状态 + [实例][下载][设置][更多] + 账户 chip + 齿轮 |
| 主列 | 问候、最近项目、固定实例、固定世界 | 启动卡、置顶实例、最近世界、存储、Java 推荐 |
| 右栏 | 日历、游玩洞察、每日挑战、新闻、当前账号 | 当前账号、活动日历、内存、崩溃历史、体检、下载源、快照 |
| 窄图标栏 | Axolotl 保留图标栏 | **LMCL 不保留**：用户明确要求移除侧栏，导航改顶部/主页内 |

### 2.3 被否决的方案

| 方案 | 否决原因 |
|---|---|
| 只把 200 px 侧栏内容改成图标栏 | 用户要求"移除左侧侧边栏"；且账户/实例/下载/设置仍有重复入口 |
| 保留 `DashboardPane` 的 2×2 网格，直接把窗口拉宽 | 卡片等宽等高，无法表达"主列 + 右信息栏"，和参考结构差距大 |
| 修改 `Controllers` 新增一个"主页"页面 | 会把首页变成第 3 个页面容器，且 `Controllers` 是硬编码注册表，新增第 7 处侵入 |
| 把 `DashboardPane` 整个删掉 | 13 的布局协议、组件注册表、显隐配置仍可复用；删除会连带影响测试与历史配置 |

**结论**：只改"外壳"——`RootPage` 去掉文本侧栏、`DecoratorAnimatedPage` 对空 `left` 不占位；新增 `HomePane` 作为首页容器，卡片仍由既有 `WidgetProvider` 创建。`DashboardPane` 保留为历史布局实现，但不再挂载。

## 3. 设计

### 3.1 页面结构

```
┌──────────────────────────────────────────────────────────────────────┐
│ 你好，<账号>              [实例] [下载] [设置] [更多]   [头像/账号] [⚙] │  header
│ 你的 Minecraft 启动器 · [无运行实例 / 启动中 / 运行中: id]              │
├───────────────────────────────────────────────┬──────────────────────┤
│ 主列（随窗口伸缩）                              │ 右栏（340 px 固定）   │
│ ┌───────────────────────────────────────────┐ │ ┌──────────────────┐ │
│ │ launch（启动卡，168 px）                    │ │ │ 当前账号（自建）   │ │
│ ├───────────────────────────────────────────┤ │ ├──────────────────┤ │
│ │ pinned-instances（置顶实例，188 px）        │ │ │ activity-calendar │ │
│ ├───────────────────────────────────────────┤ │ │ 318 px            │ │
│ │ recent-worlds（最近世界，272 px）           │ │ ├──────────────────┤ │
│ ├───────────────────────────────────────────┤ │ │ memory / crash /  │ │
│ │ storage（144 px）                          │ │ │ health / network /│ │
│ ├───────────────────────────────────────────┤ │ │ snapshot          │ │
│ │ java-recommend（168 px）                   │ │ │ 142–176 px 各     │ │
│ └───────────────────────────────────────────┘ │ └──────────────────┘ │
└───────────────────────────────────────────────┴──────────────────────┘
```

- 外层 `VBox`：header + `ScrollPane`；
- `ScrollPane` 内容 `HBox`：`mainColumn`（`HBox.setHgrow(ALWAYS)`）+ `railColumn`（固定 340）；
- 槽位高度来自 `HomePane.Slot`，只设 `prefHeight/minHeight`，不强制 `maxHeight`，卡片内部自行滚动/截断；
- 窗口变窄时 `ScrollPane` 横向滚动，不隐藏卡片、不改变槽位顺序。

### 3.2 顶部导航

| 控件 | 行为 |
|---|---|
| 问候语 | `Accounts.getSelectedAccount()`；`profileName` 为空回退 `profileID`；无账号用 `community.home.greeting.guest` |
| 副标题 | `community.home.subtitle` |
| 运行状态 | 08 事件维护：`status.none` / `status.launching` / `status.running`（带 versionId） |
| [实例] | `Controllers.navigate(Controllers.getGameListPage())` |
| [下载] | `Controllers.getDownloadPage().showGameDownloads()` + navigate |
| [设置] | `Controllers.getSettingsPage().showGameSettings(repository)` + navigate；无实例时退回启动器设置 |
| [更多] | `MenuButton`：社区设置 / 启动器设置 / 多人游戏（Terracotta，不支持时提示）/ 反馈 |
| 账户 chip | `AccountAdvancedListItem`，绑定 `Accounts.selectedAccountProperty()`，点击进入账户页 |
| 齿轮 | `CommunitySettingsPanel.open(getWindow())` |

> 导航按钮只调用上游既有页面，**不新增页面**；`Controllers` 的结构不变。

### 3.3 主列槽位

| id | 高度 | 说明 |
|---|---:|---|
| `launch` | 168 | 当前选中实例 + 启动/切换/新建/管理 |
| `pinned-instances` | 188 | 置顶实例 tile；点击选中，右键取消置顶/打开目录 |
| `recent-worlds` | 272 | 最近存档；按可用高度显示 1/3/6 条 |
| `storage` | 144 | 存储占用摘要 |
| `java-recommend` | 168 | Java 偏好/推荐 + JVM 参数两个 tab |

### 3.4 右栏槽位

| id | 高度 | 说明 |
|---|---:|---|
| 当前账号（自建，非 Widget） | auto | `AccountAdvancedListItem` + 标题；不占卡片 id |
| `activity-calendar` | 318 | 活动日历；父容器宽 340，`weeks()` 走 12 周分支 |
| `memory` | 158 | 内存指标 + 立即归还 + 开关 |
| `crash-history` | 176 | 最近崩溃 + 查看全部 |
| `health-check` | 154 | 最近体检摘要 + 复查 |
| `network` | 142 | 主源/镜像/官方兜底 + 配置按钮 |
| `snapshot` | 176 | 上次成功快照 + 回滚/标记/管理 |

> `snapshot` 在 16 落地后才注册；未落地时 `WidgetRegistry.create` 返回 null，`HomePane` 跳过该槽位（不显示空壳）。

### 3.5 显隐配置

- 配置仍读 `Metadata.HMCL_LOCAL_HOME/config/dashboard.json`（`DashboardConfig.load`）；
- 首次无文件：全部 11 个 id 写入 `items`（enabled=true，order 按 `descriptor.order()`）；
- 已有文件：按 id 判断 enabled，缺失 id 视为启用（兼容旧 10 卡配置）；
- [设置] → dashboard 分组的 `startEditing()` 打开 520 px 宽显隐对话框（CheckBox 列表），保存后写 `config.items` 并重建；
- `resetLayout()` 全部启用并重建；
- 配置写盘由 `HomePane` 的 1 s 防抖统一负责；组件内部不要直接写 `dashboard.json`。

### 3.6 侧栏移除

`RootPage.Skin` 原本构造 `AdvancedListBox sideBar`，并 `setLeft(sideBar); setCenter(getMainPage())`。v3.1 后：

```java
// RootPage.Skin
// LMCL: the 200px text sidebar has been removed. Navigation and account
// entry points now live on the community home page; the centre keeps the
// upstream MainPage so the launch button / background still work.
setCenter(getSkinnable().getMainPage());
```

`DecoratorAnimatedPageSkin` 原本无条件：

```java
pane.setLeft(control.left);
FXUtils.setLimitWidth(control.left, 200);
```

v3.1 后：

```java
if (!control.left.getChildren().isEmpty()) {
    pane.setLeft(control.left);
    FXUtils.setLimitWidth(control.left, 200);
}
```

这样空 `left` 不再占 200 px；其它真正使用 `left` 的 `DecoratorAnimatedPage` 子类行为不变。

### 3.7 运行状态与事件

`HomePane` 在构造时 `CommunityLaunchHooks.addListener(listener)`，事件可能来自任意线程，统一 `Schedulers.javafx().execute(...)` 后再改 UI：

| 事件 | UI 状态 |
|---|---|
| `REQUESTED` | `launching`（记录 versionId） |
| `PROCESS_CREATED` / `SURVIVED_THRESHOLD` | `running` |
| `EXITED_NORMAL` / `EXITED_ABNORMAL` / `ABORTED_BY_USER` / `LAUNCH_FAILED` | 移除该 versionId |

- **禁止**用 `countMangedProcesses` 猜测运行状态；
- `dispose()` 必须 `CommunityLaunchHooks.removeListener(listener)`，否则首页销毁后仍收到事件。

### 3.8 i18n

三份文件（`I18N.properties`、`I18N_zh.properties`、`I18N_zh_CN.properties`）各追加 19 个 key：

`community.home.greeting`、`greeting.guest`、`subtitle`、`status.none`、`status.launching`、`status.running`、`nav.instances`、`nav.download`、`nav.settings`、`nav.more`、`account.title`、`more.community`、`more.launcher`、`more.terracotta`、`more.feedback`、`widgets.title`、`widgets.hint`、`empty`、`readonly`。

文案格式：`community.home.greeting=Hi, %s` / `你好，%s`；`community.home.status.running=Running: %s` / `运行中：%s`。`i18n` 走 `String.format`，占位符必须一致。

## 4. 实现落盘

### 4.1 文件清单

| 文件 | 改动 |
|---|---|
| `HMCL/src/main/java/org/jackhuang/hmcl/ui/main/RootPage.java` | 删除侧栏构造；`Skin` 只 `setCenter(getMainPage())`；清理 10 个不再使用的 import |
| `HMCL/src/main/java/org/jackhuang/hmcl/ui/decorator/DecoratorAnimatedPage.java` | `DecoratorAnimatedPageSkin` 空 `left` 不 setLeft/不限宽 |
| `HMCL/src/main/java/org/jackhuang/hmcl/community/dashboard/CommunityDashboard.java` | `mounted` 类型改为 `HomePane`；`mount()` 创建 `HomePane` |
| `HMCL/src/main/java/org/jackhuang/hmcl/community/dashboard/builtin/HomePane.java` | 新增：header + 主列/右栏 + 配置/导航/事件/显隐 |
| `HMCL/src/main/resources/assets/lang/I18N*.properties` | 三份各 19 个 `community.home.*` key |

> `HomePane` 放在 `community.dashboard.builtin` 是为了复用包内 package-private 的 `BuiltinWidgets`（`caption/body/borderButton/raisedButton/dialogRoot/dialogActions`），**不是**新的公共 UI 包。

### 4.2 `HomePane` 关键骨架

```java
public final class HomePane extends VBox implements CommunitySettingsPanel.DashboardActions {
    private static final List<Slot> MAIN_SLOTS = List.of(
            new Slot("launch", 168), new Slot("pinned-instances", 188),
            new Slot("recent-worlds", 272), new Slot("storage", 144),
            new Slot("java-recommend", 168));
    private static final List<Slot> RAIL_SLOTS = List.of(
            new Slot("activity-calendar", 318), new Slot("memory", 158),
            new Slot("crash-history", 176), new Slot("health-check", 154),
            new Slot("network", 142), new Slot("snapshot", 176));
    private static final double RAIL_WIDTH = 340;

    public HomePane(MainPage mainPage, Path configPath) {
        this.mainPage = mainPage;
        this.config = DashboardConfig.load(configPath);
        this.registry = WidgetRegistry.load();
        this.context = new DashboardContext(this::currentRepository,
                mainPage.currentGameProperty(), this::hideWidget,
                config.prefs(this::markDirty));
        if (!config.readOnly() && config.items().isEmpty()) {
            config.setItems(defaultItems());
            persist();
        }
        getChildren().addAll(buildHeader(), buildScroll());
        rebuildBody();
        Accounts.selectedAccountProperty().addListener(accountListener);
        CommunityLaunchHooks.addListener(launchListener);
        CommunitySettingsPanel.setDashboardActions(this);
    }
}
```

### 4.3 组件创建

```java
DashboardWidget widget = registry.create(id, context);
if (widget == null) continue;                  // 16 未落地时 snapshot 直接跳过
widget.setPrefHeight(slot.height());
widget.setMinHeight(slot.height());
widget.setMaxWidth(Double.MAX_VALUE);
widget.initialize();
widget.requestRefresh();
```

- 数据读取由各卡片 `loadAsync` 走 `Schedulers.io()`；`HomePane` 不读磁盘；
- `HomePane` 只负责布局、显隐、导航、账号/运行状态；
- 卡片销毁时必须 `DashboardWidget.dispose()`（`HomePane.dispose()` 逐个调用）。

### 4.4 `dispose`

```java
@Override
public void dispose() {
    saveDebounce.stop();
    persistIfDirty();
    Accounts.selectedAccountProperty().removeListener(accountListener);
    CommunityLaunchHooks.removeListener(launchListener);
    widgets.forEach(DashboardWidget::dispose);
    widgets.clear();
    CommunitySettingsPanel.setDashboardActions(null);
}
```

`dispose()` 幂等；任何异常只记 `LOG.warning`，不阻断页面切换。

## 6. 风险

| 风险 | 等级 | 缓解 |
|---|---|---|
| `RootPage`/`DecoratorAnimatedPage` 是上游主页骨架，合并冲突概率高 | 高 | 两处改动都极小（删除侧栏构造 / 条件 setLeft），合并时逐行核对；每次同步上游 grep `setLeft(sideBar)` 与 `setLimitWidth(control.left, 200)` |
| `HomePane` 槽位高度写死，字体缩放/高 DPI 下卡片内容被截断 | 中 | 只设 pref/min，不设 max；卡片内部现有截断/滚动逻辑；收集用户截图后再调 |
| 右栏 340 px 在窄窗口挤压主列 | 中 | `ScrollPane` 横向滚动兜底；后续可加断点（<1000 px 时右栏移到主列下方），本步不做 |
| 旧 `dashboard.json` 的 10 卡布局/尺寸与新槽位不一致 | 中 | 按 id 读取 enabled，不看旧 colSpan/rowSpan；新槽位固定，不迁移尺寸 |
| 首页销毁后仍收到启动事件 | 中 | `dispose()` 移除 `CommunityLaunchHooks` 与账户监听；`DashboardWidget.dispose` 幂等 |
| `DashboardPane` 保留但不再挂载，形成死代码 | 低 | 文档标注；下个版本确认无回归后删除；不影响构建 |
| 无 GUI 实机验证 | 高 | 生成 Windows 测试包，由用户按 §5.2 验收；日志/截图回传 |

## 7. 回退
