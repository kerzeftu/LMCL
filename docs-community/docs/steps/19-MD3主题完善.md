## 2. 上游事实核对（v3.16.4 实测）

> 这些事实决定了本步骤"能怎么做"。旧稿里"上游是 MD2/JFoenix、我们做 MD3 是差异化"的说法只对了一半，必须按下面修正。

### 2.1 主题与取色：MonetFX 已经是上游正式依赖

| 事实 | 证据 |
|---|---|
| 取色库依赖 | `gradle/libs.versions.toml:22` `monet-fx = "0.4.0"`；`:60` `org.glavo:MonetFX`；`HMCL/build.gradle.kts:64` `implementation(libs.monet.fx)` |
| 颜色模型 | `org.glavo.monetfx.ColorScheme` / `ColorRole` / `ColorStyle` / `Contrast` / `Brightness` |
| JFoenix 现状 | 不以 Maven 依赖引入，而是**以源码形式内联**在 `HMCL/src/main/java/com/jfoenix/`（如 `JFXClippedPane`、`JFXColorPicker`）→ 上游确实处于 MD2（JFoenix 控件）与 MD3（Monet 取色）混用状态 |
| 结论 | **不要自建主题引擎，也不要重写上游控件**；我们只做"新界面跟随 token" |

### 2.2 样式加载链（决定了我们怎么挂自己的 CSS）

`HMCL/src/main/java/org/jackhuang/hmcl/setting/StyleSheets.java`：

| 位置 | 内容 |
|---|---|
| `:48-68` | 静态清单固定 4 项：字体表(0) / 主题色表(1) / 亮度表(2) / `/assets/css/root.css`(3)；字体或配色变化时**就地替换**对应项 |
| `:190-192` | `init(Scene)` 里 `Bindings.bindContent(scene.getStylesheets(), stylesheets)` |
| `:161-165` | `getThemeStyleSheet()`：默认主题（`ResolvedTheme.DEFAULT`）→ 直接返回 `/assets/css/blue.css` |
| `:167-188` | 其它主题 → 运行时生成 `* { -monet-*: <color> }`（含 `-monet-primary-seed` 与 50/80/38 透明度变体） |
| `:139-143` | 亮度 → `/assets/css/brightness-light.css` / `brightness-dark.css` |

**含义**：

- `-monet-*` 变量在**默认主题**里由 `blue.css`（59 行、58 个 token）提供，在**自定义主题**里由生成的样式表提供 → 我们的 CSS **两种情况下都能解析**；
- `scene.getStylesheets()` 被 `bindContent` 绑定到上游的可观察列表，**不要往 scene 上加我们的样式**（主题/字体切换时列表被重写，可能丢失我们的项，且等于改了上游行为）；
- 正确做法：**在我们自己的根节点上 `getStylesheets().add("/assets/css/community.css")`**（JavaFX 节点级样式表，作用于该子树，生命周期跟随节点，0 上游侵入）。

## 4. 详细实施

### 4.1 语义色映射（唯一允许的颜色用法）

| 语义 | 背景 | 文字/图标 | 使用场景 |
|---|---|---|---|
| 正常/成功 | `-monet-primary-container` 或 `.card` 默认底 | `-monet-on-primary-container` / `-monet-on-surface` | 体检"通过"、快照可用、Java 已就绪 |
| 警告 | `-monet-tertiary-container` | `-monet-on-tertiary-container` | 体检"警告"、低内存提醒、非致命降级 |
| 错误/阻断 | `-monet-error-container` | `-monet-on-error-container` | 体检"失败"、启动崩溃、快照不可用 |
| 信息/中性 | `-monet-secondary-container` | `-monet-on-secondary-container` | 提示、选中态、只读徽标 |
| 次要文字 | 透明 | `-monet-on-surface-variant` | 副标题、说明、时间戳 |
| 分隔线/描边 | — | `-monet-outline-variant` | 列表分隔、卡片内边界 |
| 不可用 | 透明 | `-monet-on-surface-variant-transparent-38` | 禁用按钮/占位文字 |
| 主操作 | `-monet-primary` | `-monet-on-primary` | 主按钮（沿用上游 `.jfx-button` 样式，不自己写） |

- **颜色不得作为唯一信息载体**：红/黄/绿状态旁必须有图标（`SVG`）+ 文字（i18n），色盲用户可辨；
- 深色模式**不写 `if (dark)` 分支**，全靠变量切换；写分支即视为不合规（code review 检查项）。

### 4.2 类型层级与间距

| 类 | 字号 | 用途 | 是否加字重 |
|---|---|---|---|
| `.community-headline` | 20px | 仪表盘大标题（"我的首页"）、对话框标题 | 600（`semibold`） |
| `.community-title` | 16px | 卡片标题、分组标题 | 600 |
| `.community-body` | 14px | 正文、数字主体 | 常规 |
| `.community-label` | 12px | 辅助说明、单位、时间戳 | 常规 |
| `.community-metric` | 20px | 卡片主数字（内存/时长） | 600 + 等宽数字（JavaFX 支持时用 `-fx-font-feature-settings: "tnum"`，不支持则用等宽字体容器） |

- 颜色仍由 `.title-label` / `.subtitle-label` / `.label` 提供 → 使用时**同时加**两个 class，如 `getStyleClass().addAll("title-label", "community-title");`；
- 间距栅格：`4 / 8 / 12 / 16 / 24`；卡片内边距 8（对齐 `.card`）、卡片间距 12（对齐 13 的 `GAP = 12`）、区块间距 16；
- 行高：JavaFX CSS 无 `line-height`；多行说明用 `Text` + `setLineSpacing(fontSize * 0.5)`，不要用多个 Label 拼；
- 圆角：卡片 4（`.card`）；按钮/输入框用上游控件默认值，**不覆盖**；
- 图标：20px（`LineComponent.DEFAULT_ICON_SIZE`），颜色随文字色（`SVG` 已接入 `-monet-*`）。

### 4.4 样式加载工具类（新增，约 30 行）

`HMCL/src/main/java/org/jackhuang/hmcl/community/ui/CommunityStyles.java`

```java
package org.jackhuang.hmcl.community.ui;

import javafx.scene.Parent;
import org.jetbrains.annotations.NotNull;

/// Loads `community.css` on a community root node (node-scoped stylesheet).
///
/// We deliberately do NOT touch `StyleSheets.init(Scene)`: its scene stylesheet list is
/// bound to an upstream observable list that is rewritten on theme/font changes, so a
/// node-scoped stylesheet is the only zero-intrusion, theme-safe option.
public final class CommunityStyles {
    private static final String COMMUNITY_CSS = "/assets/css/community.css";

    /// Applies the community stylesheet to the given subtree. Idempotent.
    public static <T extends Parent> @NotNull T apply(@NotNull T root) {
        if (!root.getStylesheets().contains(COMMUNITY_CSS)) {
            root.getStylesheets().add(COMMUNITY_CSS);
        }
        return root;
    }

    private CommunityStyles() { }
}
```

```java
    fade.setFromValue(0);
    fade.setToValue(1);
    fade.setInterpolator(Motion.EASE);
    fade.play();
} else {
    node.setOpacity(1);
}
```

| 场景 | 做法 |
|---|---|
| 卡片数据刷新 | 不闪动画；数字变化用短淡入（`SHORT2`，100ms）或直接更新 |
| 面板/对话框出现 | 用 `TransitionPane`（`setContent(node, ContainerAnimations.FADE, Motion.SHORT4)`）或上游 `JFXDialog` 默认动画 |
| 编辑模式进入/退出 | `Motion.SHORT4` 滑动 ≤ 200ms |
| 禁止 | 自定义 `Timeline` 时长 > 200ms、无限循环动画、`animationDisabled` 时仍播放 |
| 设置生效说明 | `AnimationUtils` 在类初始化时读一次 → 修改"减少动画"后**需重启**，UI 文案要写清（上游同样行为，不额外处理） |

### 附：对比度计算脚本（可复跑）

```python
# tools/theme/contrast.py — 仅标准库；输入 blue.css，输出 WCAG 对比度表
import re, sys
css = open(sys.argv[1] if len(sys.argv) > 1 else "blue.css").read()
tok = {k[len("-monet-"):]: v for k, v in re.findall(r"(-monet-[\w-]+):\s*(#[0-9A-Fa-f]{6,8})", css)}
def rgb(h): h = h.lstrip("#"); return tuple(int(h[i:i+2], 16) for i in (0, 2, 4))
def lum(c):
    def f(v):
        v /= 255
        return v / 12.92 if v <= 0.03928 else ((v + 0.055) / 1.055) ** 2.4
    r, g, b = (f(x) for x in c); return 0.2126 * r + 0.7152 * g + 0.0722 * b
def ratio(a, b):
    la, lb = lum(rgb(tok[a])), lum(rgb(tok[b])); hi, lo = max(la, lb), min(la, lb)
    return (hi + 0.05) / (lo + 0.05)
for a, b in [("on-surface", "surface"), ("on-surface", "surface-container-low"),
             ("on-surface-variant", "surface"), ("on-surface-variant", "surface-container-low"),
             ("primary", "surface"), ("on-primary", "primary"),
             ("on-primary-container", "primary-container"), ("on-secondary-container", "secondary-container"),
             ("on-tertiary", "tertiary"), ("on-error-container", "error-container"),
             ("error", "surface"), ("outline", "surface"), ("inverse-on-surface", "inverse-surface")]:
    if a in tok and b in tok:
        print(f"{a:28s} on {b:26s} {ratio(a, b):5.2f}:1")
```

> 自定义主题的 token 是运行时生成的，公式相同；取色方案可由 `Themes.getColorScheme().getColor(ColorRole.X)` 导出 hex 后喂给同一脚本。
