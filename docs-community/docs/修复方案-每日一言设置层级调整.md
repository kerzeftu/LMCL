## 1. 你的要求

原话（m22514）：

> 获取源三个字改成在线源，然后本地源和在线源都是依托于每日一言这个大类的部分，不要单开出来像分别单开两类这样，先写md讲讲你的理解

## 2. 我的理解

### 2.1 不是要改的东西

这次**不改**每日一言的数据和逻辑：

- 不改本地语料文件、在线源列表、启停状态、随机选源规则。
- 不改 10 分钟刷新、失败静默回退、缓存 TTL、退避策略。
- 不改 `DailyQuoteSettings` 的 JSON 字段，也不新增配置项。
- 不改主页顶栏的展示方式。
- 不新增上游代码侵入点。

### 2.2 要改的东西

要改的是**设置页的视觉层级和信息组织**：

1. “每日一言”是这一块唯一的**一级标题**。
2. “本地源”“在线源”不再作为与“每日一言”同级的设置分类出现，而是“每日一言”内部的**二级分组**。
3. “获取源”三个字统一改为“在线源”；错误提示里的“获取源”也一并改。
4. 本地源、在线源、预览不再各占一张卡片、各配一个大标题；它们应当收在同一张设置卡片里，用更小的分组标签区分。
5. 保留“本地源”和“在线源”两个概念，不把它们合并成同一个开关或同一类源；它们的区别仍然要一眼看得出来。

一句话：**减少的是“分类标题”的层级，不是减少“本地/在线”这两个功能分组。**

## 3. 现状与问题

### 3.2 为什么看起来像“分别单开两类”

`ComponentList.createComponentListTitle` 的实现（`HMCL/src/main/java/org/jackhuang/hmcl/ui/construct/ComponentList.java:143-163`）只是一个顶部留 8px 的 `HBox` + 普通 `Label`，没有专属 CSS 类或更小的字号。

结果是：

- 外层的“每日一言”；
- 内层的“本地源”；
- 内层的“获取源”；
- 内层的“预览”；

四个标题的字体、位置、留白几乎相同，视觉权重完全一样。用户看到的是四个并列分类，而不是“一个大类下面的三个小节”。

同时 `mainList`、`localList`、`sourceList` 是三张独立的 `options-list` 圆角卡片，行与行之间的连续感也被卡片边界切断，进一步强化了“三个独立分类”的观感。

| `community.dailyQuote.title` | 每日一言 | Daily quote |
| `community.dailyQuote.local` | 本地源 | Local sources |

| `community.dailyQuote.preview` | 预览 | Preview |
| `community.dailyQuote.source.none` | 当前没有启用的**获取源**；请先启用一个源。 | No source is enabled. Enable at least one source first. |

## 4. 建议的目标结构

### 4.1 结构图

```text
设置 → 外观
每日一言                                  ← 唯一一级标题
┌────────────────────────────────────────┐
│ 在主页显示每日一言              [开关] │
│ 联网获取                        [开关] │
│                                        │
│ 本地源                                 │  ← 二级分组标签（小字、次要色）
│ Minecraft 风味语句              [开关] │
│ 经典诗词                        [开关] │
│                                        │
│ 在线源                                 │  ← 二级分组标签（小字、次要色）
│ Hitokoto                        [开关] │
│ 今日诗词                        [开关] │
│ 自定义源…                       [开关] │
│ [添加在线源]                           │
│ 提示：启用多个在线源时……               │
│                                        │
│ 预览                                   │  ← 二级分组标签（小字、次要色）
│ “每日一言正文……”                       │
│ 状态/来源提示                          │
│                          [重新获取]    │
└────────────────────────────────────────┘
```

关键点：

- 只有“每日一言”保留与设置页其他分类同级的大标题。
- “本地源”“在线源”“预览”都在同一张卡片内部，使用小字号、次要颜色、无箭头、不可点击的分组标签。
- 三张 `ComponentList` 合并为一张；分组之间只靠标签和 1px 行分隔线区分，不再用独立圆角卡片制造新分类。
- “添加在线源”和提示文字也放进这张卡片，不再悬挂在卡片外。

### 4.2 视觉规则

| 元素 | 规则 |
|---|---|
| “每日一言” | 沿用 `PersonalizationPage` 当前的外层标题，不动 |
| 分组标签 | `subtitle-label` 风格 + 新 class `community-daily-quote-group`；字号 12–13px、次要色、非交互 |
| 设置行 | 继续使用 `LineToggleButton` / `LinePane`，不改变行高和点击行为 |
| 卡片 | 一个 `ComponentList`；行间分隔线沿用 `options-list-item`，不另画边框 |
| 添加按钮 | 卡片内单独一行，左对齐或右对齐均可；建议左对齐，和提示文字成组 |
| 提示文字 | 卡片内 `Label`，`wrapText=true`，宽度跟随卡片内容区 |
| 预览 | 卡片底部，引用文本 + 状态提示 + 右对齐的“重新获取” |

### 4.3 文案调整

只改文案，不改 key 名，避免配置和翻译 key 迁移：

- `community.dailyQuote.sources`：
  - 中文：`获取源` → `在线源`
  - 英文：`Sources` → `Online sources`
- `community.dailyQuote.source.none`：
  - 中文：`当前没有启用的获取源；请先启用一个源。` → `当前没有启用的在线源；请先启用一个源。`
  - 英文：`No source is enabled. Enable at least one source first.` → `No online source is enabled. Enable at least one source first.`
- `community.dailyQuote.local` 保持“本地源”，但它在新结构里只作为二级分组标签，不再作为一级标题。
- `community.dailyQuote.preview` 保持“预览”，同样降为二级标签。

三份 `I18N.properties`、`I18N_zh.properties`、`I18N_zh_CN.properties` 都要同步。

### 4.4 交互与状态

- “联网获取”关闭时，“在线源”分组**仍然显示**，但整组置灰、不可操作；不隐藏，避免布局跳动和用户找不到关闭原因。
- “本地源”两个开关始终可见；至少保留一份的规则不变。
- “添加在线源”在离线/关闭联网时禁用，和在线源行一起置灰。
- 动态增删在线源后，分组顺序保持“本地源 → 在线源 → 预览”，不因重建而错位。
- 预览按钮行为、提示文案、失败静默逻辑均不变。
- 不使用折叠面板：本地源/在线源必须默认全部展开，不能为了层级而把设置藏起来。

## 5. 代码改法（预计）

### 5.1 `DailyQuoteSettingsPane.java`

1. 把 `mainList`、`localList`、`sourceList` 合并为一个字段，例如 `private final ComponentList settingsList = new ComponentList();`。
2. 为统一重建卡片内容，`sourceHint` 已是字段；需要把 `previewBox`、`addSourceBar`、`onlineGroupLabel` 提升为字段，`onlineRows` 维护 `List<LinePane>`。`displayToggle`、`onlineToggle`、`localMcToggle`、`localPoetryToggle` 已是字段，可重复使用。
3. 删除三处 `ComponentList.createComponentListTitle(...)` 的调用；新增 `groupLabel(String key)` 辅助方法，返回带 `subtitle-label` 和 `community-daily-quote-group` 的 `Label`。
4. `sourceList` 不再作为独立 `ComponentList`；改为维护 `List<LinePane> onlineRows`，`rebuildSources()` 重建这些行。
5. `rebuildSources()` 的最后一步统一重建卡片内容：

```java
List<Node> rows = new ArrayList<>();
rows.add(displayToggle);
rows.add(onlineToggle);
rows.add(groupLabel("community.dailyQuote.local"));
rows.add(localMcToggle);
rows.add(localPoetryToggle);
rows.add(groupLabel("community.dailyQuote.sources"));
rows.addAll(onlineRows);
rows.add(sourceHint);
rows.add(addSourceBar);
rows.add(groupLabel("community.dailyQuote.preview"));
rows.add(previewBox);
settingsList.getContent().setAll(rows);
```

6. `addSourceButton` 外再包一个 `HBox`（例如 `addSourceBar`），使其成为卡片内的一行。
7. `sourceHint`、`previewBox` 的宽度约束改为跟随卡片内容区；`sourceHint` 保持 `wrapText=true`。
8. `updateControls()` 中原本 `sourceList.setDisable(!online)` 改为遍历 `onlineRows` 设置禁用，并同步 `addSourceButton`；`onlineGroupLabel.setOpacity(online ? 1 : 0.5)`。
9. 删除已经没有用途的 `localList` 字段和相关 `getContent().addAll`。

### 5.2 `community.css`

新增：

```css

    -fx-padding: 12px 0 2px 0;
    -fx-font-size: 12px;
    -fx-font-weight: 600;
}
```

颜色继续由 `subtitle-label` 提供，不写死 hex；M3 主题下可由 `m3-community.css` 覆盖。

### 5.3 不改的文件

- `DailyQuoteService.java`、`DailyQuoteSettings.java`、`BuiltinQuotes.java`、在线源 provider：不改。
- `HomePane.java`：不改。
- `PersonalizationPage.java`：外层“每日一言”标题保留，不改。
- 不新增上游侵入点。

## 6. 备选方案与取舍

### 方案 A：单卡片 + 小字号分组标签（推荐）

- 一个 `ComponentList`，内部用 `subtitle-label` 分组。
- 优点：视觉上只有一个大类；本地/在线仍清楚；所有设置默认可见；改动集中在一个 pane。
- 缺点：需要重写 `rebuildSources()` 的内容拼装，约半天。

### 方案 B：`ComponentSublist` 嵌套

- 用可折叠子列表承载“本地源”“在线源”。
- 不推荐：`ComponentSublistWrapper` 默认 `expanded=false`，会先折叠；带箭头和高度动画，交互更重；折叠后用户反而看不到设置。
- 除非明确希望“默认折叠的高级分组”，否则不用。

### 方案 C：只改“获取源”文案

- 只把“获取源”改成“在线源”，保留三个大标题和三张卡片。
- 不推荐：用户已明确指出“不要单开出来像分别单开两类”，只改字不解决层级。

### 方案 D：把本地/在线拆成两个二级页面

- 不推荐：增加导航层级，和“每日一言是一个设置块”的定位冲突，也没有必要。

## 8. 风险与回退

| 风险 | 处理 |
|---|---|
| `ComponentList` 行 wrapper 的 16px padding 让分组标签缩进过深 | 用 CSS 调 `community-daily-quote-group` 的 padding；实机截图确认 |
| 动态重建列表导致正在操作的开关失去焦点 | 重建后对当前操作控件 `requestFocus()`；增删源本来就会整行重建，可接受 |
| 在线源行禁用后分组标签仍可点击 | 分组标签用 `Label`，本身不可交互；仅做透明度变化 |
| 提示文字在卡片内宽度计算错误 | `sourceHint.setMaxWidth(Double.MAX_VALUE)`，必要时绑定内容区宽度 |
| 分组标签仍被当成一级标题 | 字号 12px、次要色、无外层 8px 顶部留白；实机对比“每日一言” |

回退：只回退 `DailyQuoteSettingsPane.java`、三份 i18n 和 `community.css` 四处；数据与逻辑不受影响，旧配置无需迁移。

### 11.2 结构

`getChildren()` 只剩一个 `settingsList`（`ComponentList`），其行顺序为：

1. `displayToggle`：在主页显示每日一言；
2. `onlineToggle`：联网获取；
3. `localGroupLabel`：小字“本地源”；
4. `localMcToggle` / `localPoetryToggle`；
5. `onlineGroupLabel`：小字“在线源”；
6. `onlineRows`：每个在线源一个 `LinePane`；
7. `addSourceBar`：添加在线源按钮；
8. `sourceHint`；
9. `previewGroupLabel`：小字“预览”；
10. `previewBox`：引用文本、状态和 [重新获取]。

三个分组标签由 `configureGroupLabel` 统一设置：`subtitle-label`、`community-daily-quote-group`、`maxWidth=MAX_VALUE`、左对齐。`community-daily-quote-group` 在 `community.css` 中定义为 `-fx-padding: 12 0 2 0; -fx-font-size: 12px; -fx-font-weight: 600;`。

### 11.3 交互

- 在线源行改为字段 `onlineRows`；`rebuildSources()` 重建行后调用 `rebuildSettingsList()`，增删源不再替换整张卡片。

- “获取源”相关文案统一为“在线源”：
  - `community.dailyQuote.sources`：`Online sources` / “在线源”；
  - `community.dailyQuote.source.none`：“当前没有启用的在线源；请先启用一个源。” / “No online source is enabled...”；
  - 三份语言文件同步。
