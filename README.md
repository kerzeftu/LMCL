# Lumina Minecraft Launcher（LMCL）

**项目现处于半弃坑状态。** 这里保留的是基于 [HMCL v3.16.4](https://github.com/HMCL-dev/HMCL/tree/v3.16.4) 开发的 Minecraft 启动器半成品。不承诺继续维护、修复或发版；界面显示的 `1.0.0` 不代表稳定版已经验收。

## 作者的话

这段时间，市面上出现了不少 Minecraft 启动器。我发现，我们既没能和现有选择拉开明显差距，也不能保证长期维护。对还在等更新、愿意试用和反馈的朋友，说一声抱歉。我想把这个半成品留在这里，当作一份纪念。也许有一天我会再把它捞起来继续做，但那是以后的事了。

—— 指尖的宇宙 kerze

## 名字的寓意

LMCL 是 **Lumina Minecraft Launcher** 的缩写。Lumina 有「光」的意象：在已经有许多优秀启动器的环境里，希望它也能成为一缕微光，陪玩家走进方块世界。

## 已完成与未完成

| 已实现并保留在源码中 | 暂停时仍未完成或未验收 |
| --- | --- |
| 独立名称、图标和关于页；可配置双列主页、Material 3 Expressive 界面和经典主题。 | Windows 实机回归仍未完成；实例选中后快照按钮的命中问题待复现，右列底部毛玻璃向下延伸尚未实现。 |
| 启动前体检、崩溃归档和诊断导出；实例快照、管理、对比与回滚。 | 独立 OAuth、正式更新源、签名与发布流程尚未收尾；没有随本次文档留档重制完整 Windows 绿色包。 |
| 自定义下载源、设置导入导出、Java 发行版偏好、JVM 参数向导和内存回收基础功能。 | 下载管理与分段下载、Windows 内存守护进程和跨平台回归未交付。 |

「已实现」不等于所有平台或场景已验收。最近留存的 LMCL 验证记录对应文档版本 `v3.17.35`：358 个测试用例，跳过 2 项，无失败；没有完整的 Windows 实机验收。`m3expressive36-patch` 只是历史测试补丁，不是可独立运行的绿色包。
